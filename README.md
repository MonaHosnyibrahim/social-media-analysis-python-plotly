# social-media-analysis-python-plotly

## 📊 Project Overview
This project focuses on analyzing social media data using Python and creating interactive visualizations with Plotly.

The analysis explores reach across different post types and years and uses correlation analysis to understand relationships between numerical variables.

## 🛠️ Tools & Libraries
- Python
- Pandas
- NumPy
- Plotly
- Matplotlib / Seaborn (for visualization practice)

## 🔍 Analysis Performed
- Data aggregation using `groupby()`
- Average Reach by Year
- Average Reach by Post Type
- Interactive Line Chart
- Interactive Bar Chart
- Interactive Correlation Heatmap
- Correlation analysis using `.corr()`
- Interactive hover information
- Chart customization and axis control

## 📈 Visualizations
### Average Reach by Year
Interactive line chart showing average reach across years.

### Average Reach by Post Type
Interactive bar chart comparing the average reach of different post types.

### Correlation Heatmap
Interactive heatmap showing correlations between numerical variables.

## ▶️ How to Run
1. Download or clone the repository.
2. Open `Social_Media_Analysis_Plotly.ipynb` in Jupyter Notebook, JupyterLab, or VS Code.
3. Install the required libraries:

```bash
pip install pandas numpy plotly matplotlib seaborn
```

4. Run the notebook cells from top to bottom.
